{%- comment -%} Renders one publication record from _data/publications.yml. Papers with a `description` become a
/ pair (citation shown, description hidden until expanded); papers without render as a plain citation. The title is wrapped in .pub-title so every title stands out (bold), whether or not it links out. Citation and description both go through `markdownify` so links, emphasis and the \\(..\\) math convention render consistently. " | remove: "

" | strip -%} {%- if r.description -%}
